# IDDS — Interface Detailed Design Specification

## Purpose

Holds **Interface Detailed Design Specifications**: field-level, schema-level, and protocol-level detail required to implement and test an interface unambiguously.

## Scope

- Exact request/response or event schemas
- Field types, constraints, enums, and examples
- Headers, correlation IDs, pagination, filtering
- Mapping to persistence models where relevant
- Backward/forward compatibility notes per revision

## Alignment

IDDS is the detailed elaboration of [`../IDS/`](../IDS/). Canonical API references may be published or mirrored under [`../API/`](../API/); data mappings may reference [`../Database/`](../Database/).
