# IDS — Interface Design Specification

## Purpose

Holds **Interface Design Specifications** for individual interfaces (service endpoints, events, UI–backend contracts) at a design level suitable for implementation planning.

## Scope

- Interface identity, owners, and consumers
- Operations/messages and behavioral semantics
- Error models and idempotency expectations
- Versioning and compatibility rules
- Non-functional constraints specific to the interface

## Alignment

IDS refines [`../AIDS/`](../AIDS/) and is further detailed by [`../IDDS/`](../IDDS/). Public HTTP/RPC catalogs may also appear under [`../API/`](../API/).
