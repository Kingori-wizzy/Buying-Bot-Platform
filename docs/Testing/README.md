# Testing — test strategy documentation

## Purpose

Holds **test strategy and plans** for unit, integration, end-to-end, performance, and security testing across the monorepo.

## Scope

- Test pyramid and ownership per app/package
- Environments and test data policy
- Coverage expectations and quality gates
- CI integration with `pnpm test` / Turbo pipelines
- Traceability from SRS acceptance criteria to test cases

## Alignment

Testing verifies [`../SRS/`](../SRS/) and [`../SDS/`](../SDS/). CI behavior is cataloged in [`../github.md`](../github.md). Coding expectations are in [`../standards/coding-standards.md`](../standards/coding-standards.md).
