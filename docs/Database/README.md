# Database — data architecture documentation

## Purpose

Holds **database and data-store documentation**: logical/physical models, retention, migrations strategy, and data ownership across the platform.

## Scope

- Logical data models and bounded contexts
- Physical schemas and store choices (when selected)
- Migration and versioning approach
- PII/commerce data classification references (detail in Security)
- Backup, retention, and archival expectations at the data layer

## Alignment

Database design supports [`../SDS/`](../SDS/) and [`../SRS/`](../SRS/). Sensitive-data handling must align with [`../Security/`](../Security/) and [`../../SECURITY.md`](../../SECURITY.md).
