# SRS — Software Requirements Specification

## Purpose

Holds **Software Requirements Specifications** that translate business needs into precise, testable software requirements.

## Scope

- Functional requirements for web, admin, API, AI, worker, and future mobile
- Non-functional requirements (performance, availability, security, observability)
- User roles, use cases, and acceptance criteria
- System interfaces at a requirements level (not detailed design)
- Traceability to BRS items

## Alignment

SRS derives from [`../BRS/`](../BRS/) and constrains [`../SDS/`](../SDS/), [`../API/`](../API/), and [`../Testing/`](../Testing/). Architecture boundaries follow [`../EAD/`](../EAD/).
